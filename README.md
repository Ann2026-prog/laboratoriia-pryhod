# Лабораторія пригод · Анна Сюмар

Готовий статичний сайт для GitHub Pages.

## Перше розміщення
1. Увійдіть у GitHub як Ann2026-prog.
2. Створіть репозиторій laboratoriia-pryhod, оберіть Public та додайте README.
3. Розпакуйте цей ZIP на комп’ютері.
4. У репозиторії оберіть Add file → Upload files.
5. Перетягніть УВЕСЬ вміст розпакованого архіву, зокрема папки. Не завантажуйте ZIP як один файл. index.html має бути безпосередньо в корені репозиторію, поруч із папками quests, memos, lesson, resources, class-hours.
6. Натисніть Commit changes.
7. Settings → Pages → Source: Deploy from a branch → main → / (root) → Save.
8. Дочекайтеся завершення публікації. Адреса: https://Ann2026-prog.github.io/laboratoriia-pryhod/

## Склад сайту
Квести для 5–9 класів, пам’ятки, криголами настрою, вихідні квитки, виховні години та 4 презентації для самостійного перегляду.

## Подальші оновлення
Нові або змінені файли потрібно завантажувати в цей самий репозиторій зі збереженням структури папок. GitHub Pages опублікує зміни. Зберігайте резервну копію перед великими змінами.

## Про дані
Сайт не збирає імена або оцінки учнів. Деякі квести зберігають прогрес лише в браузері. Файли публічного репозиторію доступні всім. Не додавайте списки учнів, контакти дітей чи інші приватні дані.

## Презентації
Презентації відображаються як зображення слайдів. Анімація та відео PowerPoint у цьому режимі не відтворюються.

## Примітка
Архів не містить облікових даних, ключів чи службових налаштувань попереднього хостингу. Налаштування GitHub Pages та публікацію у вашому обліковому записі потрібно завершити окремо.
